# power-rate-calc-interac

Residential power-rate interactive HTML board.

## Run

Open `/home/runner/work/power-rate-calc-interac/power-rate-calc-interac/index.html` in a browser.

## Features

- City search for Canada (Toronto), USA (New York), Hong Kong, Macau, and China (Shanghai)
- Animated hourly rate board by time of day
- Current date format like `Nov. 7th, 2026`
- Real tariff-based rates with source references shown in the UI
