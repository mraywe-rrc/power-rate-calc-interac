# power-rate-calc-interac

Residential power-rate interactive HTML board.

## Run

Open `/home/runner/work/power-rate-calc-interac/power-rate-calc-interac/index.html` in a browser.

## Features

- City search for Canada, USA, Hong Kong, Macau, and China (including Toronto, London ON, Moncton NB, Laval QC, Brandon MB, Selkirk MB, Edmonton AB, Coquitlam BC, New York, Portland OR, Shanghai, Shenzhen, Zhongshan, Taishan, Meizhou, Ningbo, Hangzhou, Qingdao, Hegang, and Shenyang)
- Animated hourly rate board by time of day
- Current date format like `Nov. 7th, 2026`
- Real tariff-based rates with source references shown in the UI
- Interactive monthly calculator sheet rows A2:D145 for gas and EV cumulative scenarios
- Local gas-liter price is auto-filled from selected city/profile with reference source
